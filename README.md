# TraffLabels

Traffolyte labels marketing site for Perth / WA. Brand: TraffLabels, under the Stik Stickers group.

## Stack

Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui. `lang="en-AU"`.

## Local

```bash
npm install
npm run dev
npm run build
```

## MVP routes

- `/` — trade + personalise
- `/traffolyte-labels-perth/`
- `/what-is-traffolyte/`
- `/switchboard-labels/`
- `/traffolyte-labels/malaga/`
- `/traffolyte-labels/wangara/`
- `/traffolyte-labels/welshpool/`
- `/order/` — choose Design online or Upload a list
- `/order/?mode=designer` — TraffLabels canvas designer
- `/order/?mode=upload` — CSV schedule upload (`colour,size,text,qty`)
