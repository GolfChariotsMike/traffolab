# TraffoLab

Traffolyte labels marketing site for Perth / WA. Working brand name under the Stik Stickers group.

## Stack

Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui. `lang="en-AU"`.

## Local

```bash
npm install
npm run dev
npm run build
```

## MVP routes

- `/` — trade + personalise
- `/traffolyte-labels-perth/`
- `/what-is-traffolyte/`
- `/switchboard-labels/`
- `/traffolyte-labels/malaga/`
- `/traffolyte-labels/wangara/`
- `/traffolyte-labels/welshpool/`
- `/order/` — designer stub
